## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| **Boot-Abbild** | Windows-PE-Abbild, mit dem der Client im Netzwerk startet und die Aufgabensequenz ausführt. |
| **Betriebssystem-Abbild** | WIM-Datei mit dem zu installierenden Windows. |
| **Aufgabensequenz** | Geordnete Liste von Schritten, die den Rollout durchführen. |
| **Bereitstellung (Deployment)** | Verknüpfung einer Aufgabensequenz mit einer Sammlung. |
| **PXE-Responder ohne WDS** | Dienst von Configuration Manager (`SccmPxe`), der PXE-Anfragen ohne WDS beantwortet. |
| **Unbekannter Computer** | Gerät, das Configuration Manager noch nicht kennt. |
| **`_SMSTSInWinPE`** | Variable, die angibt, ob die Aufgabensequenz in Windows PE läuft. |

## Aufgabe

### Teil 1: Komponentenplan

*(Lerneinheit 9.1, Praxisaufgabe 1)*

Zeichne, welche Objekte für eine Bereitstellung nötig sind (Boot-Abbild, Betriebssystem-Abbild, Aufgabensequenz, Verteilungspunkt, Bereitstellung, Sammlung) und in welcher Reihenfolge sie zusammenspielen. Ordne zu, was in Windows PE und was im installierten Windows abläuft (Learn: Task-Sequence-Variable `_SMSTSInWinPE`).

### Teil 2: Boot-Abbild und PXE

*(Lerneinheit 9.2, Praxisaufgabe 2)*

1. Öffne in der Konsole *Software Library → Operating Systems → Boot Images*. Notiere Paket-ID und Windows-PE-Version des x64-Boot-Abbilds, das der Standort anlegt (ob und wie, *nicht bestätigt*).
2. In den Eigenschaften des Boot-Abbilds, Reiter *Data Source*: aktiviere „Deploy this boot image from the PXE-enabled distribution point“. Im Reiter *Customization* (nur im Labor): „Enable command support (testing only)“.
3. Verteile das Abbild mit *Update Distribution Points*.
4. Am Verteilungspunkt `DEPLOY01` aktiviere: „Enable PXE support for clients“, „Allow this distribution point to respond to incoming PXE requests“, „Enable unknown computer support“, „Enable a PXE responder without Windows Deployment Service“. Der Verteilungspunkt muss lokal sein, damit er PXE-Anfragen beantwortet (laut Learn).
5. Setze „Require a password when computers use PXE“ mit einem Kennwort vom Kursleiter. Lass die Firewall-Regeln von Configuration Manager anlegen (Dialog „Review Required Ports for PXE“).
6. Prüfe, dass der Dienst „ConfigMgr PXE Responder Service“ (`SccmPxe`) läuft:

   ```powershell
   Get-Service SccmPxe | Format-Table Name, Status, StartType
   ```

7. **Befund festhalten:** Learn verlangt für PXE x86- und x64-Boot-Abbilder auf dem Verteilungspunkt, die ADK-Seite nennt 32-Bit-Windows-PE für Windows 11 als nicht unterstützt. Prüfe im Labor, ob für UEFI-x64-Clients ein x64-Abbild genügt, und dokumentiere die Beobachtung mit Version.

### Teil 3: Abbild und Aufgabensequenz

*(Lerneinheit 9.3, Praxisaufgabe 3)*

1. Lege das Abbild `\\DEPLOY01\Images\W11-ENT-REF-2026-11-v2-export.wim` unter *Operating System Images* an. Der Quellpfad ist als UNC-Pfad anzugeben; das Computerkonto des Standortservers braucht Leserechte (*nicht bestätigt*). Verteile es an den Verteilungspunkt und prüfe in der Überwachung den Inhaltsstatus.
2. Erstelle eine Aufgabensequenz **TS-Win11-Standard** aus einem vorhandenen Abbild (Assistent „Install an existing image package“, Name *nicht bestätigt*) mit den Schritten: *Format and Partition Disk (UEFI)*, *Apply Operating System*, *Apply Windows Settings*, *Apply Network Settings* (zunächst Arbeitsgruppe), *Setup Windows and Configuration Manager*. Wähle das Boot-Abbild aus Teil 2.

### Teil 4: Bereitstellung und erster Lauf

*(Lerneinheit 9.4, Praxisaufgabe 4)*

1. Stelle die Aufgabensequenz für die Sammlung der unbekannten Computer bereit („All Unknown Computers“, Name *nicht bestätigt*). Verfügbarkeit: „Only media and PXE“ (eine der drei Optionen laut Learn).
2. Starte `CL01` per PXE, gib das PXE-Kennwort ein, wähle die Aufgabensequenz und beobachte den Ablauf. Drücke in Windows PE bei Bedarf **F8** (Befehlszeile) und lies `X:\Windows\Temp\SMSTSLog\smsts.log`.
3. Erfasse die Dauer je Phase:

   | Phase | Dauer |
   |---|---|
   | PXE-Start bis Windows PE | ? |
   | Abbild anwenden | ? |
   | Erster Start | ? |
   | Client-Installation | ? |

4. Prüfe in der Konsole, ob `CL01` als Gerät mit Client erscheint.

## Hinweise

- „Enable command support“ (F8) ist nur für das Labor gedacht. Wer F8 in WinPE nutzen kann, kann Dateien lesen, die in der Bereitstellung stehen.
- Der Inhalt muss auf dem Verteilungspunkt liegen, bevor die Aufgabensequenz läuft. Prüfe den Inhaltsstatus, bevor du `CL01` startest.
- Die drei Verfügbarkeitsoptionen sind laut Learn: „Configuration Manager clients, media, and PXE“, „Only media and PXE“ und „Only media and PXE (hidden)“.
- Wenn `CL01` bereits bekannt ist, greift die Sammlung der unbekannten Computer nicht mehr (Modul 10).
- Bei Fehlern lies zuerst `smsts.log`; der Fundort wechselt im Ablauf (Modul 14).

## Kontrollfragen

1. Was unterscheidet ein Boot-Abbild von einem Betriebssystem-Abbild?
2. Warum braucht PXE einen lokalen Verteilungspunkt, und was bedeutet „PXE-Responder ohne WDS“?
3. Warum ist „Enable command support“ nicht für den Produktivbetrieb gedacht?
4. Warum muss der Inhalt auf dem Verteilungspunkt liegen, bevor die Aufgabensequenz läuft?
5. Welche drei Verfügbarkeitsoptionen nennt Learn für PXE-Bereitstellungen, und was unterscheidet „Only media and PXE“ von „Configuration Manager clients, media, and PXE“?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Zielzustand:** Boot-Abbild verteilt, Verteilungspunkt mit PXE-Responder, Abbild importiert und verteilt, Aufgabensequenz `TS-Win11-Standard`, `CL01` ist per PXE bereitgestellt und erscheint in der Konsole mit Client, Phasendauern notiert.

**Kontrollfragen**

1. Das Boot-Abbild ist das kleine Windows PE, mit dem der Client startet und die Aufgabensequenz ausführt. Das Betriebssystem-Abbild ist das Windows, das auf die Platte kommt.
2. Der Client sendet seine Anfrage im lokalen Netz; ein lokaler Verteilungspunkt beantwortet sie. „Ohne WDS“ heißt: Der Dienst `SccmPxe` von Configuration Manager übernimmt die PXE-Antwort, WDS wird nicht benötigt. Preis: kein Multicast (Learn).
3. Mit F8 öffnet jeder, der am Gerät sitzt, eine Befehlszeile in WinPE und kann Dateien (zum Beispiel Kennwörter in Skripten) auslesen.
4. Die Aufgabensequenz lädt Boot-Abbild, Betriebssystem-Abbild und Pakete vom Verteilungspunkt. Fehlt der Inhalt dort, scheitert der Schritt „Apply Operating System“.
5. Die drei Optionen: „Configuration Manager clients, media, and PXE“, „Only media and PXE“, „Only media and PXE (hidden)“. Bei „Only media and PXE“ sehen Clients mit Configuration-Manager-Client die Bereitstellung nicht im Software Center.

</details>
