# CompTIA Tech+ / ITF+ (FC0-U71) – Lernskript

Lernskript zur Vorbereitung auf die Einstiegszertifizierung von CompTIA, die laut Skript zurzeit als **Tech+** (Prüfungscode FC0-U71) geführt wird und den früheren **IT Fundamentals (ITF+, FC0-U61)** nachfolgt. Zwölf Module erklären jede Lerneinheit zusammenhängend und von Grund auf, mit Beispielen (meist Python, Shell oder SQL), typischen Fehlern und einem Praxisbezug. Am Ende jedes Kapitels stehen Übungsaufgaben, die Lösungen folgen getrennt dahinter.

## Wichtig: Was dieses Repository (noch) ist

- Es enthält das **Skript als Markdown**, ein Kapitel pro Modul (`skript.md`), dazu [Einleitung](docs/skript-einleitung.md) und [Quellenverzeichnis](docs/skript-quellenverzeichnis.md) im Ordner `docs`.
- Eine eigenständige Übungsreihe mit Aufgaben, Lösungen und Beispieldateien je Modul ist **noch nicht** Teil des Repositories.
- Laut Skript wurden die Python-Beispiele bei der Erstellung ausgeführt und die gezeigten Ausgaben stammen daraus; Windows- und PowerShell-Befehle wurden nicht ausgeführt. Für dieses Repository wurden die Listings **nicht erneut ausgeführt**.
- Inhalt und Beispiele beruhen auf dem Lehrplan und auf fachlicher Recherche. Prüfungsdetails, Produktnamen und Versionen ändern sich; maßgeblich sind die aktuellen Prüfungsziele (Exam Objectives) von CompTIA.
- Hinweise zu Datenschutz und anderen rechtlichen Themen sind fachliche Orientierung und keine Rechtsberatung.
